# Dataset Card — synthitd

## Summary

Synthetic, reproducible, multi-surface workplace telemetry for insider-threat
detection research, with graded ground-truth labels grown from a Critical-Pathway
intent model. Produced by the generator in this repository; every dataset is a pure
function of its `SimConfig` and can be regenerated byte-for-byte from the config
stored in `manifest.json`.

## Intended use

- Training and evaluating insider-threat detection (ITD) models: supervised,
  unsupervised/anomaly, sequence, and graph methods.
- Early-warning / risk-ranking research (via precursor labels + latent risk target).
- LLM-as-detector and RAG-over-user-history research (per-user context is explicit).
- Robustness studies under partial sensor visibility.

**Out of scope / prohibited uses.** This data and generator are for defensive and
academic research only. They model behaviour as detection observables and MITRE
technique *labels*; they are not a source of operational attack procedures and must
not be used to target real individuals or systems.

## Files

| file | description |
|---|---|
| `events.jsonl` | full labelled ground-truth stream (one JSON event per line) |
| `observed.jsonl` | stream after the observability filter (what a detector gets) |
| `employees.json` | org: role, team, manager, privilege, access, OCEAN, predisposition, population |
| `episodes.json` | one record per activated insider episode (pathway, onset, technique ids) |
| `labels_userday.csv` | per (user, day): graded label, rank, latent risk, counts |
| `ground_truth.json` | per-employee latent trajectory summary |
| `manifest.json` | config + summary + render/observability reports |
| `cert/` | CERT r6.2-compatible export (see `export_cert`) |

## Event schema (`events.jsonl`)

| field | type | notes |
|---|---|---|
| `event_id` | str | stable, monotonic (`e000000001`) |
| `ts` | float | Unix seconds (UTC) |
| `channel` | enum | logon, idp, device, file, email, http, chat, ticket, vcs, dlp, endpoint, hr |
| `actor` | str | employee id |
| `action` | str | machine verb, e.g. `file.copy`, `http.upload`, `idp.auth` |
| `attrs` | object | structured, label-free facts (sizes, counts, hosts, recipients, flags) |
| `label` | enum | **graded** ground truth (see below) |
| `episode_id` | str | groups an insider episode, else `""` |
| `technique_ids` | list | MITRE ATT&CK technique id labels (malicious/precursor only) |
| `risk_state` | float | latent Critical-Pathway risk 0..1 (early-warning target) |
| `render` | object/null | rendered free text (`subject`/`body`/`message`/…); null if not rendered |
| `causal_parent` | str | event id of the direct cause, else `""` |

### Labels (graded, multi-resolution) — requirement R5

| label | meaning |
|---|---|
| `benign` | ordinary activity |
| `anomalous_benign` | **hard negative**: suspicious-looking but legitimately explained (travel, on-call, promotion, approved bulk export) — paired with an observable `hr.context` event |
| `precursor` | concerning activity on an *armed* pathway, before the act (early-warning window) |
| `malicious` | the insider act itself |

Binary ITD collapses to `malicious` vs rest; graded tasks use `max_label_rank` in
`labels_userday.csv`. Benign events never carry technique ids.

## Statistics (shipped sample)

- 120 employees, 70 days, tech domain, seed 11.
- 797,328 full events; 705,641 observed (imperfect sensor).
- Populations: 7 insider, 10 anomalous-benign, 103 normal; **5 of 7 insiders
  activate** within the horizon (the rest remain latent-risk negatives).
- Event labels: 792,555 benign / 4,560 anomalous-benign / 139 precursor / 74
  malicious. User-day malicious prevalence **0.38 %** (CERT-r6.2-like sparsity).
- Stylized facts: after-hours fraction 0.19, work-hour concentration 0.81,
  weekend fraction 0.02 — flagged `plausible`.

Scale freely via `SimConfig` (`n_employees`, `horizon_days`, `insider_prevalence`,
`anomalous_benign_rate`, `channel_coverage`, `seed`).

### Scaled reference instance (`configs/finance_r62_sparse.yaml`)

1,000 employees · 120 days · finance · seed 20 · `activity_scale` 0.8. **9,132,134
full events** (7,827,513 observed); 8 insiders, 6 activate; 80 anomalous-benign
employees; 24,103 anomalous-benign / 199 precursor / **61 malicious** events;
**0.02 % malicious user-day prevalence** (sparser than CERT r6.2). Compact reports in
[`../reference/`](../reference/); regenerate the full stream with
`scripts/make_reference.sh` (multi-GB, gitignored). At this prevalence a supervised
sequence model (`sequence_logreg`) reaches PR-AUC 0.44–0.61 and ~2 weeks of detection
lead across splits, while static baselines sit near PR-AUC 0.1 — see
[`BENCHMARK.md`](BENCHMARK.md).

## Known limitations

- **Behaviour is model-based, not learned from real logs.** Baseline rates and role
  deltas are hand-set; realism is asserted via stylized-facts checks, not validated
  against a proprietary ground-truth corpus (none is public at scale).
- **Free text is intentionally non-discriminative.** The renderer is label-blind, so
  prose carries no intent signal; this is a feature for avoiding NLP shortcuts but
  means the dataset does not exercise content-based detection of malicious wording.
- **Psychology is a stylised abstraction** of the Critical Pathway / SOFIT literature,
  not a validated psychometric instrument.
- **Technique labels are illustrative**, attached at the level of detection
  observables; they are not a claim of exact real-world procedure fidelity.
- **Determinism is within a fixed library stack**; NumPy/SDK version changes can shift
  draws. Pin versions for exact reproducibility.

## Provenance & ethics

Fully synthetic — no real people, accounts, credentials, or messages. Names are drawn
from a fixed neutral token list. Designed so published artifacts cannot be used to
impersonate a real organisation or individual. See the literature review for the
behavioural-science sources that inform the model.
