# Dataset paper

LaTeX source for the **synthitd** dataset paper:
*"synthitd: A Reproducible, Endogenous-Intent Synthetic Benchmark for Insider-Threat
Detection."*

## Files
- `main.tex` — the paper (standard `article` class; only mainstream CTAN packages,
  so it compiles offline with any TeX Live / MiKTeX install).
- `references.bib` — bibliography (natbib / `plainnat`).
- `Makefile` — `make` → `main.pdf`.

## Build
```bash
cd paper
make                 # pdflatex + bibtex + pdflatex x2  -> main.pdf
# or, if you have them:
latexmk -pdf main.tex
tectonic main.tex
```

## Where the numbers come from
Every figure in the paper is taken from artifacts regenerated by the repository, not
hand-typed estimates:
- Dataset statistics: `../sample/manifest.json`, `../reference/summary.json`.
- Reference baselines (Table 4): `../reference/benchmark.json`
  (`PYTHONPATH=. python -m synthitd.cli benchmark --data <dir>`).
- SOTA recipe ablation (Table 5): `../reference/sota_comparison.json`
  (`PYTHONPATH=. python scripts/sota_experiment.py 300 120 5`).
- UBS-Transformer comparison (Table 6): `../reference/ubs_transformer_comparison.json`
  (`PYTHONPATH=. python scripts/ubs_experiment.py 400 120 13 12`).

See `../docs/SOTA_COMPARISON.md`, `../docs/BENCHMARK.md`, and
`../docs/LITERATURE_REVIEW.md` for the long-form versions and full threats-to-validity.
